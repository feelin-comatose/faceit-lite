# FACEIT Lite

Лёгкий и кастомный десктоп-клиент для FACEIT на **Tauri 2**: бинарник весит около 5–10 МБ и работает на системном WebView2, без встроенного Chromium, как в Electron.

## Что умеет

**Режим «сайт в трее»** (включён по умолчанию)
- при запуске открывается только наша панель, а faceit.com спит в трее;
- спрятанный сайт на Windows переводится в «невидимый» режим WebView2 (ничего не рисует, держит минимум памяти), но JS работает, поэтому алерт о матче срабатывает;
- «матч найден» → сайт сам всплывает для Accept и вето карт, а в панели загорается статус;
- кнопка «Открыть/Спрятать FACEIT» в панели, клик по трею открывает панель;
- выключается в «Настройках» (`tray_mode`), применяется после перезапуска.

**Главное окно — faceit.com в своей обёртке**
- своя тема: фон, шрифт, масштаб, скрытие любых блоков по CSS-селектору плюс полностью свой `faceit.css`;
- режим экономии: отключает анимации, transitions и видео;
- **матч найден** → системное уведомление, звук и окно вылезает поверх (без автоклика, жать Accept нужно самому);
- сворачивание в трей, глобальные хоткеи;
- тема перечитывается на лету, перезапуск не нужен.

**Окно статистики** (`Ctrl+Shift+F`)
- профиль: ELO, уровень, прогресс до следующего лвла, последние матчи (K/D, ADR, HS%), статы по картам;
- **разбор лобби**: заходишь в комнату матча, и панель сама подтягивает обе команды со средним ELO, K/D и WR каждого игрока, плюс WR команд по картам с подсказкой пиков и банов;
- тема настраивается полностью: цвета, шрифт, скругления, прозрачность и свой `panel.css`.

## Важно
- **FACEIT AC всё равно должен быть запущен**, иначе матчи играть не получится. Это не замена античиту, а замена тяжёлому окну/вкладке.
- Для статистики нужен бесплатный ключ: <https://developers.faceit.com> → App Studio → создать приложение → API Keys → **Server-side**. Его нужно вставить во вкладку «Настройки».
- Детект «матч найден» эвристический: он ищет кнопку с текстом из `match_found_regex`. Если FACEIT поменяет текст кнопки, регулярку можно поправить в настройках.

## Сборка (Windows)
Нужны [Rust](https://rustup.rs), [Node.js 20+](https://nodejs.org) и WebView2 (в Windows 10/11 обычно уже есть).

```bash
npm install
```
```bash
npm run build
```
Готовый установщик будет в `src-tauri/target/release/bundle/nsis/`, а голый exe — `src-tauri/target/release/faceit-lite.exe`.

Для разработки с горячей пересборкой: `npm run dev`.

Без локальной установки можно так: залей репо на GitHub, открой вкладку Actions → **Build Windows** → Run workflow, и exe появится в артефактах.

## Автообновление
Клиент при запуске проверяет `latest.json` из последнего GitHub Release. Если там новая версия, в панели появляется кнопка «Обновить»: клиент скачает установщик, проверит подпись, поставит обновление и перезапустится. Проверку можно запустить и вручную: трей → «Проверить обновления».

Работает только для **установленной** версии (setup.exe). Portable-exe обновляется вручную.

**Настройка (один раз):** нужен ключ подписи обновлений.
1. Открой репо → Settings → Secrets and variables → Actions → New repository secret.
2. Имя `TAURI_SIGNING_PRIVATE_KEY`, значение — содержимое приватного ключа (файл `updater.key`).
3. Публичная половина ключа уже лежит в `src-tauri/tauri.conf.json` → `plugins.updater.pubkey`. Если генерируешь свою пару (`npx tauri signer generate -w updater.key`), замени и её.

Ключ **не теряй**: без него следующие обновления не встанут у тех, кто уже установил клиент.

**Выпуск версии:**
1. Подними версию в `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml` и `package.json`.
2. Actions → Build Windows → Run workflow → `release_tag` = `vX.Y.Z` (должен совпадать с версией).

## Кастомизация
Настройки лежат в `%APPDATA%\dev.faceitlite.app\` (трей → «Папка настроек»):

| файл | что это |
|---|---|
| `config.json` | все настройки (то же, что во вкладке «Настройки», только руками) |
| `faceit.css` | твой CSS поверх faceit.com |
| `panel.css` | твой CSS для окна статистики |

После правок жми трей → **«Перечитать тему и конфиг»**.

Совет: включи `"devtools": true`, перезапусти клиент, потом ПКМ → Inspect, и ищи, что скрыть или перекрасить. У FACEIT классы хэшированные, поэтому селекторы лучше строить через `[data-testid]`, `[aria-label]` или `[class*="..."]`.

## Безопасность
Сайту faceit.com доступна только одна команда приложения, `page_event` (матч найден, комната, ready). API-ключ живёт только в Rust-части и на страницу не попадает.
